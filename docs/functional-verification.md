## 本轮发现并修复的问题

1. 监控关键字按字符串保存、重开时直接 `.join()` 导致加载失败，现统一迁移和规范化。
2. 监控任务链接仍向旧 iframe 父窗口发消息，现通过受限 IPC 定位原生主窗口；修正事件包装丢失参数的问题。
3. 应用与流程仅有高级 JSON 表单，现增加业务表格、筛选、历史和操作表单，并按旧服务实现核对正文/查询参数位置。
4. 通用点击收尾把末页按钮、只读编辑按钮重新启用，现恢复业务禁用状态。
5. 删除最后步骤和空代码块无法暂存、重复粘贴编码冲突、重命名或删除后跳转悬空，现区分草稿与保存校验，并维护同作用域引用。
6. 刷新快照覆盖尚未提交属性输入、切换后旧表单提交、生成流程取消跳转后误用旧会话，现分别保护输入、绑定表单平台、创建前确认工作区切换。
7. 新增原生执行策略控件，统一整数、非负数、状态、失败策略及未知参数校验；原始 JSON 仍可审阅。
