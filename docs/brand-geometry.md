# RA 标识构造

外侧浅青色 #90CFCB 粗主笔与右上斜线在顶部自然连接成一笔；内侧灰青色 #56818A 细笔独立保留。连接顶角以相切二次曲线柔化。暖白圆弧、圆外白色右腿和深蓝灰底板保留；圆弧表达微微低头的人物轮廓。

以画板边长 L = 256 为基准，φ = (1 + √5) / 2：

- 主体构造高度 H = L / φ ≈ 158.217。
- 基础三角形宽度 W = H / φ ≈ 97.783；左侧双笔沿用其斜率，并向左偏移，给右侧圆弧留出空间。
- 主体中心线上下留白 = (L − H) / 2 ≈ 48.892；圆端笔画各向外延伸半个线宽。
- 笔画粗细 = H / φ⁵ ≈ 14.266。
- 左斜线粗细 = S × (1 + 1 / φ³) ≈ 17.634，比常规笔画加重约 23.6%。
- 内侧细笔宽度为外主笔的 1 / φ，两笔完全平行，水平中心线间距为外主笔宽度 × φ。
- 外侧粗主笔、连接弧及圆内右斜线统一使用浅青色和同一笔宽；暖白圆弧覆盖与右下白腿的交点。
- 顶部以外侧主笔与右斜线中心线的交点为二次曲线控制点，两侧等量裁切 T = 2H / φ³ ≈ 74.700，使直线与曲线切线方向严格一致。曲线顶点保持在原构造上留白高度 (L − H) / 2，避免连接后整体变高。
- 底板圆角半径 = L / φ³ ≈ 60.433。
- 基础构造顶点位于画板水平正中 L / 2；左主笔水平左移 S × φ，投影笔上端略缩短以避开金色内斜线。
- 人物头部的构造圆直径 D = H / φ ≈ 97.783，半径 r = D / 2 ≈ 48.892。
- 圆心 C = (L / 2, (L − H) / 2 + r)，开放弧从 −60° 连续绘制至 120°，转过 180°，两端采用圆帽。
- 开放弧使用单个 SVG 圆弧命令，曲率恒为 1 / r，无分段连接、折点或曲率突变。下缘高度为 (L − H) / 2 + D ≈ 146.675。

黄金比例约束画板、主体高宽、笔画、头部直径与留白。开口方向用于表达低头思考的姿态，圆弧并非黄金螺旋。图标不展示辅助线。

生产资源位于 `src/assets/ra-mark.svg`、`src/assets/app.png`、`src/assets/app.ico`。ICO 包含 16、24、32、48、64、128、256 像素版本；`geometry.json` 记录精确构造值。运行 `electron tools/build-icon.js` 可以从同一几何定义重新生成，无需字体或网络服务。

Windows 打包由 `tools/after-pack.js` 在本地嵌入 ICO 和产品信息，不依赖下载外部资源编辑工具。写入后校验原有清单和 Electron ASAR 完整性资源保持一致。`signAndEditExecutable` 关闭的是构建器自带的编辑与签名步骤；本项目自己的图标嵌入仍会执行。
