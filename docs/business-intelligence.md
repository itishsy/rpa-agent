# 社保、公积金自动上下文与执行诊断

运行与诊断模式根据任务、应用参数及当前执行证据自动核对主体、所属期、人数金额和业务状态。来源冲突、待处理和未知结果保留为待核，不猜测缺失值。

Agent 保留 get_business_context、trace_flow_variable、get_diagnosis 和 record_diagnosis，用于自动读取字段来源、追踪变量和提出具体修改建议。这些能力服务于运行与诊断，不依赖人工配置面板。

执行核验仍要求当前版本、当前账户、新鲜完整且唯一的最终页面。技术成功不代表业务成功，证据不足时返回 UNKNOWN，审核中或银行处理中返回待处理。

右上角菜单保留执行明细、停止、占用核对、运行当前/选中步骤/候选、续跑、运行中补充、重新读取账户、执行证据及 MCP。会话检查点继续用于工作页恢复、加密证据和中断执行核对，不提供历史归档浏览入口。

相关单元测试验证来源冲突、账户绑定、变量追踪、状态映射、人员对账及过期证据；桌面回归验证运行、候选、执行证据与 MCP。
